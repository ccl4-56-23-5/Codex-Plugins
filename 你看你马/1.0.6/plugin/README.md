# 你看你马 1.0.6

Codex 桌面程序在前台时，按 Ctrl+Shift+左Alt+N 并松开按键开启；同一程序的 ChatGPT 和 Work 页面也属于此范围。为避免 AltGr 误触，请使用左 Alt。也可在 Codex 插件详情页中点击“手动开启 → 开启隐私幕布”。本版也提供 Codex 内控制页和侧栏快捷动作；当前客户端可能需要在侧栏“探索”中固定该入口。

Windows 锁屏时幕布自动停止并释放输入拦截，快捷键监听也会卸下；系统解锁后监听恢复。Windows 解锁后，需要时在 Codex 内再次开启。幕布开启时，实体键盘输入密码并按 Enter 解锁；初次安装密码为123456，升级保留已有密码。修改密码在 Codex 控制页或插件设置中操作。

本版没有桌面、开始菜单、托盘或在其他应用中生效的全局快捷键入口。幕布不调用 Windows 锁定，也不暂停任务。应用层幕布不替代系统安全锁定。
