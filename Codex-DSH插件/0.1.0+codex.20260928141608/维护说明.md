# 0.1.0 源码

`plugin/scripts/mcp-server.mjs` 接收 Codex 的 `open_new_conversation` 调用，再交给 `open-desktop-chat.ps1`。PowerShell 脚本通过 Windows UI Automation 新建会话，使用 Unicode SendInput 输入正文，以桌面出现用户消息作为发送回执。默认工作区取自 `~/.dsh/storages/workspace.json`。

`plugin/pnpm-lock.yaml` 锁定 MCP 依赖。安装包含运行依赖，单独检出源码时在 `plugin` 中运行 `pnpm install --frozen-lockfile`。旧版匹配中文 DSH 控件名。读取模型回复和验证最高指令由后来的版本实现。
