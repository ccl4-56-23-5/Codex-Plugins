# 初版安装说明

此目录归档 DeepSeek Harness Desktop 0.1.0 的源码与 Windows 安装包。[DSH 控制桥](../../DSH-Control插件/README.md)提供当前的控制入口。

复现旧版时，从本目录下载 ZIP 并解压，在 PowerShell 运行 `.\install.ps1`。安装脚本用本机路径生成 MCP 配置并登记个人插件。DSH 安装位置不同时，传入 `-DshExe`。在解压后的 `plugin` 目录运行 `node scripts/smoke-test.mjs` 可检查 MCP 工具列表。

归档包取自带依赖的最后一份本地安装包。将其中的本机 MCP 路径改为模板，并让冒烟脚本默认只列工具。旧版桌面操作逻辑随源码保留。
